# 🤖 Discord Verification & Role Code Bot

Бот для Discord на Python (`discord.py`), который генерирует проверочные коды доступа в админ-чате через команду `/panel` и выдаёт роли участникам через окно верификации (**Last step to be verified!**).

---

## ✨ Возможности

- 🎛️ **Админ-панель по команде `/panel`**: Доступна строго администраторам в админ-чате. Меню с кнопками генерации кодов, выбора ролей, просмотра списка и отправки кнопки верификации.
- 🔑 **Генерация кодов формата `XXXXXX`**:
  - Генерация 6-значных читаемых кодов (например, `7K9AB2`) или произвольного кода.
  - Привязка к любой роли на сервере.
  - Лимит использований: 1 человек, N человек или бесконечно.
  - Срок действия (в часах или бессрочно).
- 🕵️ **Окно верификации в точности как на скриншоте**:
  - Сообщение с кнопкой **Verify** в канале верификации.
  - При нажатии открывается модальное окно:
    - Заголовок: `🕵️ Last step to be verified!`
    - Поле: `CAPTCHA Code *` (с плейсхолдером `XXXXXX`).
  - После ввода кода участник мгновенно получает назначенную роль.
- 🛡️ **Защита от абуза и повторного ввода**:
  - Один и тот же участник не может использовать один код повторно.
  - База данных SQLite (`aiosqlite`) исключает сбои и гонки запросов.
  - Кнопка **Verify** постоянная (`Persistent View`) — **работает даже после перезапуска бота**.
- 📊 **Полная статистика (`/code_info`)**:
  - Отображает дату создания, статус и список участников, которые активировали код.

## 🚀 Быстрый старт

### 1. Создание бота в Discord Developer Portal
1. Перейдите на портал разработчиков: **https://discord.com/developers/applications**
2. Нажмите **New Application** в правом верхнем углу, введите имя бота и нажмите **Create**.
3. Перейдите во вкладку **Bot** слева:
   - В блоке **Privileged Gateway Intents** ОБЯЗАТЕЛЬНО включите переключатель **Server Members Intent** (нужен для выдачи ролей участникам).
   - Нажмите **Save Changes**.
   - Нажмите **Reset Token**, подтвердите действие и **скопируйте полученный токен** (он понадобится для `.env`).

### 2. Приглашение бота на ваш сервер
1. Перейдите во вкладку **OAuth2 -> URL Generator**:
   - В блоке **Scopes** отметьте галочками: `bot` и `applications.commands`.
   - В появившемся блоке **Bot Permissions** отметьте:
     - `Manage Roles` (Управлять ролями)
     - `Send Messages` (Отправлять сообщения)
     - `Embed Links` (Встраивать ссылки)
     - `View Channels` (Просматривать каналы)
2. Скопируйте сгенерированную внизу ссылку, откройте её в браузере и добавьте бота на свой сервер.

> ⚠️ **ВАЖНО (ИЕРАРХИЯ РОЛЕЙ В DISCORD):**
> Discord запрещает ботам выдавать роли, которые находятся выше или на одном уровне с ролью самого бота!
> Зайдите в **Настройки сервера -> Роли** и **перетащите роль вашего бота ВЫШЕ** тех ролей, которые он должен выдавать участникам.

---

### 3. Настройка и запуск

1. В папке с ботом откройте файл `.env` и вставьте ваш токен:
   ```env
   DISCORD_TOKEN=ваш_скопированный_токен_здесь
   DATABASE_PATH=bot_database.db
   CODE_PREFIX=ROLE
   ```
2. Для запуска просто дважды кликните по файлу:
   ```text
   run.bat
   ```
   *(Или запустите в терминале: `py bot.py`)*

После запуска бот выведет:
```text
Бот успешно запущен как: ИмяБота
Успешно синхронизировано N слэш-команд(ы) глобально.
Бот готов к работе!
```

## 📖 Как пользоваться

### Для администраторов:

| Команда | Описание |
|---|---|
| `/panel` | Открывает админ-панель генерации кодов в админ-чате (кнопки создания, списков и отправки верификации). Доступна только администраторам. |
| `/post_redeem_box [канал]` | Отправляет в указанный канал публичное сообщение с кнопкой **Verify**. |
| `/code_create [роль] [uses] [expires_hours] [custom_code] [note]` | Быстрая генерация кода `XXXXXX` одной командой прямо в чате. |
| `/code_list` | Показывает список всех кодов сервера, их статус, количество активаций и срок. |
| `/code_info [код]` | Показывает подробную карточку кода со списком пользователей, которые его активировали. |
| `/code_revoke [код]` | Досрочно деактивирует код. |

### Для участников:
1. Нажать зеленую кнопку **«Verify»** в канале верификации.
2. Откроется окно в точности как на скриншоте:
   - **Заголовок**: `🕵️ Last step to be verified!`
   - **Поле**: `CAPTCHA Code *`
3. Участник вводит код формата `XXXXXX` и нажимает **Submit**.
4. Бот мгновенно выдает назначенную роль в чате.
*(Также участники могут активировать код командой `/redeem [код]`).*

## 🛠️ Файловая структура

- `bot.py` — Основной файл бота, регистрация слэш-команд и запуск.
- `database.py` — Асинхронный модуль базы данных SQLite (`aiosqlite`) для хранения кодов и истории активаций.
- `views.py` — Интерактивные компоненты Discord UI (кнопки, модальные окна ввода, выпадающие списки ролей и каналов).
- `config.py` — Загрузка конфигурации и переменных окружения.
- `run.bat` — Скрипт быстрого запуска для Windows.
- `.env` — Конфигурационный файл с токеном бота.
- `requirements.txt` — Список зависимостей Python.
